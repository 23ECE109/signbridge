MediaPipe Hands

21 hand landmarks tracked per frame at 30+ FPS directly in your browser. No data leaves your device.

🎯

3-Tier Confidence

HIGH → auto-speak. MED → disambiguation dialog. LOW → asks you to sign again. No silent mistranslations.

🔊

Web Speech API

Translations are spoken aloud using the browser's built-in TTS — works on Chrome, Edge, Safari.

🔒

Zero Upload

Camera frames are processed locally in WebAssembly. No video, no landmarks, no text ever leaves your browser.

💾

Correction Memory

Click any history chip to re-speak it. Wrong translation? The system notes it for the session.

⚡

Snapdragon Optimized

The Python desktop version uses the Snapdragon Hexagon NPU for 52µs/frame landmark inference — 1000× faster than CPU.
